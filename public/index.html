对接配置

同步（sso 服务 weaver provider）

WEAVER_BASE_URL=http://<本机>:9100
WEAVER_HR_AUTH_MODE=ip        # 或 token（POST /api/ec/dev/auth/applytoken）
WEAVER_ACTIVE_STATUSES=0,1,2,3

泛微 SSO（sso 服务 oauth2 provider）

OAUTH2_AUTHORIZE_URL=http://<本机>:9100/sso/oauth2.0/authorize
OAUTH2_TOKEN_URL=http://<本机>:9100/sso/oauth2.0/accessToken
OAUTH2_USER_INFO_URL=http://<本机>:9100/sso/oauth2.0/profile
OAUTH2_CLIENT_ID=mock
OAUTH2_CLIENT_SECRET=mock
OAUTH2_USERNAME_MAP=attributes.workcode
OAUTH2_MEMBER_NAME_MAP=attributes.lastname
OAUTH2_CONTACT_MAP=attributes.mobile
OAUTH2_SOURCE_ID=weaver

接口清单

用途接口
HR tokenPOST /api/ec/dev/auth/applytoken（headers: appid / secret）
分部分页POST /api/hrm/resful/getHrmsubcompanyWithPage（body: {params:{pagesize,curpage}}）
部门分页POST /api/hrm/resful/getHrmdepartmentWithPage
人员分页POST /api/hrm/resful/getHrmUserInfoWithPage（支持 departmentid 逗号多值 / subcompanyid1 单值 / workcode 过滤）
OAuth2 登录页GET /sso/oauth2.0/authorize?client_id&redirect_uri&response_type=code&state
OAuth2 tokenPOST /sso/oauth2.0/accessToken（form: grant_type/client_id/code/redirect_uri/client_secret）
OAuth2 用户信息GET /sso/oauth2.0/profile（Authorization: Bearer …）

环境变量

PORT=9100                       # 监听端口
DATA_FILE=./data/orgs.json      # 数据文件
MOCK_EXPECT_APP_ID=             # applytoken 校验 appid（空=不校验）
MOCK_EXPECT_SECRET=             # applytoken 校验 secret（空=不校验）
MOCK_STRICT_TOKEN=0             # 1=HR 业务接口强制携带有效 token
MOCK_SSO_ACTIVE_STATUSES=0,1,2,3 # SSO 登录页展示的状态范围
MOCK_AUTHORIZE_PATH=/sso/oauth2.0/authorize
MOCK_TOKEN_PATH=/sso/oauth2.0/accessToken
MOCK_PROFILE_PATH=/sso/oauth2.0/profile
